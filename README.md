# 📊 داشبورد تحلیل عملکرد فروش | Sales Performance Dashboard

## معرفی پروژه | Overview

این پروژه یک داشبورد تحلیلی طراحی‌شده در Power BI برای بررسی عملکرد فروش، تحلیل شاخص‌های کلیدی عملکرد (KPIs)، شناسایی روندها و پشتیبانی از تصمیم‌گیری مبتنی بر داده است.

This project is an interactive Power BI dashboard designed to analyze sales performance, monitor key performance indicators, identify trends, and support data-driven business decisions.

---

## 🎯 اهداف پروژه | Project Objectives

- تحلیل روند فروش در بازه‌های زمانی مختلف
- بررسی شاخص‌های کلیدی عملکرد
- شناسایی محصولات و بخش‌های پرفروش
- تحلیل ابعاد مختلف عملکرد فروش
- کمک به تصمیم‌گیری بهتر بر اساس داده‌ها

- Analyze sales trends over different periods
- Monitor key performance indicators
- Identify top-performing products and segments
- Evaluate sales performance across different dimensions
- Support data-driven decision-making
